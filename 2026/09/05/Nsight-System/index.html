Nsight_System

2026-09-05 nsight system

默认情况下，Nsight Systems在应用程序的整个运行过程中收集性能分析数据，但同时提供了两种通过插入代码以限制性能分析范围的方法：

  1. 限制对CUDA程序分析的范围：在包含了头文件cuda_profiler_api.h的情况下，使用cudaProfilerStart()开始分析，cudaProfilerStop()结束分析。
  2. 限制对CPU活动分析的范围：NVIDIA Tools Extension API (NVTX)

从CLI界面分析

必须以管理员身份在Windows系统上运行CLI

两种命令行格式：

  1. nsys [global_option]
    全局选项包含：-h/–help， -v/–version

    • 短选项和对应参数中间用一个空格连接，长选项和对应参数用等于号连接
    • –duration –kill none ？？

  2. nsys [command_switch][optional command_switch_options][application] [optional application_options]

    • command_switch包括：analyse、export、launch、profile、import等；
    • 将选项设置为profile即意为启动并开始分析程序，使用格式：nsys [global-options] profile [options] [application] [application-arguments]

示例

nsys profile

sudo nsys profile

nsys profile –run-as=

若–sample为none，–cpuctxsw默认值为none，程序启动后默认值变为process-tree

若–sample不为none，–cpuctxsw的值被硬编码为与前者相同的值
