响应时间（执行时间、运行时间、挂钟时间）：完成某任务需要的总时间
性能 = 1 / 执行时间
CPU执行时间（CPU时间） 用户CPU时间 CPU性能
系统CPU时间 系统性能
吞吐率（带宽）：单位时间内完成的任务数量
时钟周期数（时钟周期）

CPI：指令平均时钟周期数
MPI：每秒百万条指令数

指令寄存器 Instruction Register : 存放当前正在译码、执行的指令
程序计数器 Program Counter(或Instruction Pointer) : 追踪下一个指令的地址

存储字长 数据总线宽度

机器字长 计算机位数 CPU寄存器位数

主存储器：
MDR 取决于存储字长/数据总线宽度，通常32/64位
MAR 取决于存储单元数量，通常32/64位
