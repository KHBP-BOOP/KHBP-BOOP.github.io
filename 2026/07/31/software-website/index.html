1. 动态监控与性能分析工具（真实运行数据）

如果你需要获取 真实 CUDA 程序运行过程中 内存的分配、释放、搬运时间线或层级命中情况：

① NVIDIA 官方分析套件（首选）

  • NVIDIA Nsight Systems (NSYS)

  • 用途：宏观时间线分析。

  • 可视化图表：可以清晰地看到随时间推进，Host-to-Device (H2D)、Device-to-Host (D2H) 以及 Device-to-Device 的内存拷贝时间段，以及 Kernel 占用 GPU 内存的宏观变化趋势。

  • NVIDIA Nsight Compute (NCU)

  • 用途：微观 Kernel 级内存层级与访问分析。

  • 可视化图表：提供自动生成的 Memory Workload Analysis（内存工作负载架构图），直接画出当前 Kernel 在 Registers ➔ Shared Memory/L1 Cache ➔ L2 Cache ➔ Global Memory (DRAM/HBM) 之间的吞吐量与数据流向，还能精准分析 Bank Conflict（Bank 冲突） 和 Memory Coalescing（内存合并访问）。

② 深度学习/框架级内存剖析器

  • PyTorch Memory Profiler / PyTorch CUDA Memory Snapshot

  • 网址/工具：torch.cuda.memory._record_memory_history() + pytorch.org/memory_viz

  • 用途：将 PyTorch 模型的 GPU 内存分配/释放过程导出为 HTML，以堆叠图/时间线图的形式直观展示显存的动态占用与碎片化情况。

  • OpenXLA / TensorBoard Memory Viewer

  • 用途：可视化 XLA 编译下 Tensor 随算子执行在内存中的生命周期与峰值内存布局。

2. 静态原理图与架构设计工具（画论文/文档/PPT）

如果你是为了撰写论文、技术文档或教程，需要手动画出 CUDA 的内存布局（如 Matrix Tiling 矩阵分块、Thread Block 到 Shared Memory 的映射、Memory Access Pattern 掩码等）：

① 极简手绘 & 交互式绘图网站（最推荐）

  • Excalidraw (excalidraw.com)

  • 优势：非常适合画 CUDA 内存块（Grid -> Block -> Thread）、Shared Memory 数组分格和指针偏移。手绘风格清晰美观，支持快捷绘制网格阵列。

  • Draw.io (Diagrams.net) (app.diagrams.net)

  • 优势：功能完备。内置丰富的 Table/Grid 元素，非常适合精准画出二维/三维 Tensor 在内存中的一维扁平化存储，以及带箭头的内存数据流转图。

  • Eraser.io (eraser.io)

  • 优势：支持 Diagram-as-Code（用代码生成架构图），适合快速生成内存流动逻辑图。

② 学术论文与精细绘制（代码生成）

  • LaTeX + TikZ

  • 优势：顶级学术期刊（IEEE/ACM）绘制 CUDA 内存访问模式（如 Coalesced vs Uncoalesced access、Shared memory bank conflicts）的标准工具。

  • 推荐库：bytefield 宏包（专门画内存字节布局）或 TikZ matrix（画多维数组和指针映射）。

  • Mermaid.js

  • 优势：可直接嵌在 Markdown 或 GitHub 文档中，适合画内存生命周期的 Sequence Diagram（时序图）或 State Diagram（状态机）。

3. CUDA 内存交互与教学学习网站

如果你想直观学习/演示 CUDA 线程索引与内存映射关系：

  • CUDA Grid & Block Visualizer（如 llm.c 社区或 GitPages 上的各类 CUDA visualizer）

  • 输入 blockDim 和 gridDim，在线实时渲染线程与内存地址计算公式（如 idx = blockIdx.x * blockDim.x + threadIdx.x）的对应关系。

  • Polly / Polyhedral Visualizers

  • 针对循环分块（Tiling）与 Shared Memory 搬运算法（如 Matrix Multiplication 优化）的可视化推演。
