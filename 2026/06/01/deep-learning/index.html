缩放点积注意力是具体的计算公式，是多头注意力的核心计算单元。
多头注意力是对缩放点积注意力的结构化拓展，它通过并行多个不同的线性投影空间来捕捉多角度的语义

encoder与decoder的输出

  • 都表示任一token语义

  • encoder：输入源序列，无因果掩码但包含用于忽略填充位 的 Padding 掩码，理解各token深层语义，重复多次。

  • decoder：多层encoder执行结束后，输入目标序列，流经因果掩码自注意力子层，此时各token的语义基于自身及其左侧上下文得出；随后在交叉注意力子层中，融合由encoder最终输出的完整上下文，得到深层语义，重复多次

多层encoder块执行结束后，再执行decoder块

每一层decoder的输出都包含任一token的多种语义且丰富程度且不断变深

输入源序列，无因果掩码（但包含用于忽略填充位 的 Padding 掩码）。采用双向自注意力机制（Bidirectional Self-Attention），使得各层 token 能够同时捕获左右双向的上下文信息，从而充分理解各 token 的深层语义

输入目标序列，在自注意力层（Self-Attention）引入了因果掩码机制（Causal Mask）。这确保了在训练阶段，目标序列中各 token 在当前层的表征仅能结合自身及左侧已生成的上下文信息，从而防止未来信息泄露（Data Leakage）。随后，Decoder 通过交叉注意力机制（Cross-Attention / Encoder-Decoder Attention），将自身的中间表征（作为 Query）与 Encoder 最终输出的完整上下文表征（作为 Key 和 Value）进行动态融合，从而实现基于源语言上下文的目标语言生成

交叉注意力，注意力的计算源来自两个地方，即融合encoder输出以及decoder掩码结果；

自注意力，注意力的计算源来自一个地方，即输入自身的序列。

原始transformer架构
推理过程 第一个输出token基于输入序列，之后的token基于输入序列以及生成的序列
训练过程 输入源序列、目标序列，输出包含“每个位置可能的token概率”的矩阵

注意力头

一个注意力头（Head）是由 Q, K, V 矩阵中特定的一组列向量组合构成的，它包含了所有 Token 在该子空间下的投影，相当于不同的滤镜或观察视角。

每个注意力头不需要看完整的 512 维特征，只需要看分给它的 64 维特征，并在该低维子空间内独立计算一套注意力权重。最后，所有头的观察结果（列）再拼接（Concat）起来，恢复成完整的 512 维向量。
