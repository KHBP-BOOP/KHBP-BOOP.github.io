任何 Linux 系统需要与之通信的设备都必须在内核代码中加入其驱动程序。驱动程序相当于应用程序和硬件设备的“中间人”，允许内核同设备之间交换数据。
向 Linux 内核中插入设备驱动的方法有两种

  1. 将驱动程序编译入内核
  2. 凭借内核模块概念，将设备驱动模块加入内核，设备驱动在加入和移除时均无需像方法一一样重新编译内核代码

命令选项
-F 名称后显示/则为目录 名称后显示*则为可执行文件。未安装彩色终端仿真器情况下使用。
-a 显示隐藏文件，它们通常以 . 开头，用来保存配置信息。
-R 显示当前目录的所有内容及其子目录的所有内容
-l 使用长列表格式输出，显示文件的详细信息

cp

命令选项
-i 强制 shell 询问是否需要覆盖已有文件
-R 递归地复制整个目录的内容

命令的最后一个参数对应的文件或目录不存在时，创建新文件并复制、或创建目录并将源目录下内容复制至目标目录下（取决于源是文件还是目录）；存在时，覆写该文件或复制至目标目录下

当有多个源时，destination必须保证存在；
这是为了防止误操作：假如你打错了，cp lots-of-files wrong-dir 不应该自动创建 wrong-dir 而把文件撒到当前目录

只有一个源（一个文件或一个目录）时，destination不存在时会自动创建。

Linux 会为系统的每个设备都创建一种称为“节点”的特殊文件，与设备的所有通信都是通过设备节点完成的。每个节点都有一个唯一的数值对，包括一个主设备号和一个次设备号，供 Linux 内核标识。类似的设备会被划分到相同的主设备号下，次设备号用于标识主设备组下的某个特定设备

unset命令：
_=某个变量
其中_表示上一条命令的最后一个参数，即上一次执行unset语句时执行的是 unset 某个命令
