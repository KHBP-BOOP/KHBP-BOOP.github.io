python虚拟环境

创建 Python 虚拟环境就是在当前目录下生成一个独立文件夹（习惯命名为 .venv、venv 或 env），用于隔离项目的 Python 解释器与第三方依赖包，文件夹内部通常包含：

  • pyvenv.cfg
    标识该目录为虚拟环境的关键文件，记录了基础 Python 解释器的系统路径（home）、版本号，以及是否允许调用系统全局安装包（include-system-site-packages = false）

  • bin/
    存放可执行文件与控制脚本：
    python ：当前环境的 Python 解释器（通常是指向系统 Python 解释器的符号链接）
    pip ：该环境专用的包管理工具
    activate ：Bash shell中的激活脚本

  • lib/pythonX.Y/site-packages/
    存放通过pip install安装的所有第三方库。这是虚拟环境体积最大的地方，实现了项目间依赖库的物理隔离

  • include/
    包含编译具有 C/C++ 扩展的第三方 Python 包时所需的头文件

当执行激活脚本时，系统会将 .venv/bin 路径插入到系统环境变量 PATH 的最前端，此时在终端输入 python 或 pip 时，系统会优先匹配并调用 .venv 目录内的可执行文件；Python解释器启动后读取 pyvenv.cfg ，会将第三方包的搜索路径定位到 .venv/…/site-packages 目录

位置参数 关键字参数

关键字参数必须跟在位置参数后面

def f(pos1, pos2, /, pos_or_kwd, *, kwd1, kwd2):
———– ———- ———-
| | |
| 位置或关键字 |
| - 仅限关键字
– 仅限位置
函数定义中未使用 / 和 * 时，参数可以按位置或关键字传递给函数

def Multiply(a, b = 1): #b为缺省参数
return a * b
def Multiply(a = 1, b = 1): #a, b为缺省参数
return a * b
def Multiply(a, b):
return a * b
对于参数是否要缺省处理，一般都处理或都不处理，或重要的缺省处理 然后放在后面。

形参的缺省值只会生效一次

print(*objects, sep=’ ‘, end=’\n’, file=sys.stdout, flush=False)
objects – 复数，表示可以一次输出多个对象。输出多个对象时，需要用 , 分隔。
sep – 用来间隔多个对象，默认值是一个空格。
end – 用来设定以什么结尾。默认值是换行符 \n，我们可以换成其他字符串。
file – 要写入的文件对象。
flush – 输出是否被缓存通常决定于 file，但如果 flush 关键字参数为 True，流会被强制刷新。
