git documentation

2026-08-28 git

配置、initialize本地repo

两种初始化的方式

  1. git init
  2. git clone [directory name]
    pull下repo的所有数据，并check out最新版本的代码
    可选的命令选项directory name。指定项目根目录的名称

常规工作流

Git将文件分为两类
untracked file - 不在上一次快照中的文件，只有一种状态untracked
tracked file - 在上一次快照中的文件，有unmodified，modified，staged三种状态

git add .
暂存每一个未跟踪或未暂存的文件

无需跟踪的文件，其文件模式应被写入 .gitignore ，避免被add至暂存区

对已跟踪的文件（包括提交后暂未更改的文件、add到暂存区的文件，它们的状态为已暂存或未修改）进行编辑后，Git发现文件相较于上一次commit记录的快照发生了改变，此时将其标记为modified，等待开发者选择性地暂存和提交

git commit [-a] -m “something…”
运行commit命令会记录位于暂存区的文件的快照

可选命令选项 -a 的作用：commit前自动暂存每一个已被跟踪的文件，此前无需运行git add相关命令
一次提交应对应一个修改

git diff
查看未暂存的文件的更改
git diff –staged 或 git diff –cached
查看已暂存、待提交的文件的更改。–staged和–cached是同义词

忽略某个特定文件或文件模式

指定不再跟踪的文件以忽略它们
.gitignore 只对未跟踪文件生效，对于已追踪的文件没有影响。
